# 五子棋 AI（Minimax + α-β 剪枝）

一个基于 Python 与 tkinter 的 15×15 五子棋人机对战程序，使用 Minimax 搜索与 α-β 剪枝决策，并通过棋型模式匹配的启发式评估函数对局面打分。

## 功能特性

- 人机对战与双人对战两种模式
- 可调节 AI 搜索深度（2 ~ 6 层，默认 4 层）
- 悔棋与重新开始
- 棋盘最后一步红框标记
- AI 思考期间界面不卡死（after 延迟触发）

## 项目结构

```
wuziqi/
├── board.py    # 棋盘模块：数据结构、落子、胜负判定、候选点生成
├── ai.py       # AI 模块：评估函数、Minimax 搜索、α-β 剪枝
├── main.py     # 主模块：tkinter 图形界面、对弈流程控制
└── README.md
```

## 环境要求

- Python 3.x
- 仅依赖 Python 标准库（`tkinter`），无需额外安装第三方包

## 运行方法

```bash
python main.py
```

程序启动后会弹出五子棋棋盘窗口，黑方先行（人类执黑）。

## 操作说明

- **落子**：在棋盘交叉点点击鼠标左键
- **模式切换**：顶部单选框可在「人机对战」与「双人对战」之间切换，切换后自动重开
- **AI 深度**：调整 Spinbox 可设置搜索深度（2 ~ 6），数值越大 AI 越强但思考越慢
- **重新开始**：清空棋盘重新开始
- **悔棋**：人机模式下一次撤销 AI 与人类各一步；双人模式撤销一步

## AI 算法说明

### 1. 候选走法生成

只考虑已有棋子周围 2 格范围内的空位（`get_empty_neighbors(radius=2)`），用集合去重，将候选点从全盘 225 个压缩到 28 ~ 60 个。

### 2. 评估函数

对 15 行、15 列及两条对角线方向上所有长度不小于 5 的线（约 72 条）进行扫描，将每条线翻译成字符串（己方棋子为 1、空位为 0、对方棋子为 2，两端各补一个 2 把边界当墙），用模式匹配识别棋型并累计分值。

最终评估值：

```
score = 己方棋型总分 × 1.0 − 对方棋型总分 × 1.1
```

防守权重（1.1）略高于进攻权重（1.0），使 AI 在做活三与堵对方活三之间更倾向于先防守。

### 3. Minimax + α-β 剪枝

- MAX 层（AI 行棋）：最大化评估值，更新 α
- MIN 层（对手行棋）：最小化评估值，更新 β
- 共用判据 `beta <= alpha`：当 MIN 方能压到的上界不超过 MAX 方已确认的下界时，剪去剩余兄弟节点
- 根节点只更新 α 不剪枝，保证每个候选点都有确切分数
- 根层候选点按试落子后的评估分降序排序，提升剪枝效率

## 模块说明

### board.py — Board 类

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `place` | `row, col, player` | `bool` | 落子，成功返回 True |
| `undo` | `row, col` | `bool` | 悔棋，清除该点棋子 |
| `get_winner` | — | `int \| None` | 返回获胜方（1 黑 / 2 白），无则 None |
| `is_full` | — | `bool` | 棋盘是否已满 |
| `get_empty_neighbors` | `radius=2` | `list` | 已有棋子周围 2 格内的空位列表 |

### ai.py — AI 类

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `evaluate` | `board` | `float` | 局面评估函数 |
| `get_best_move` | `board` | `(r, c) \| None` | 带 α-β 剪枝的最佳走法 |
| `_minimax` | `board, depth, alpha, beta, is_max` | `float` | 递归搜索主体 |

### main.py — GomokuApp 类

| 方法 | 说明 |
|------|------|
| `on_click` | 鼠标点击，像素坐标换算为行列 |
| `make_move` | 落子、判定胜负、轮换执棋、触发 AI |
| `ai_move` | 调用 AI.get_best_move 并执行 |
| `undo_move` | 悔棋 |
| `reset_game` | 重新开始 |

## 性能说明

- 深度 2：单步约 0.08 秒
- 深度 4：开局单步约 2 秒，中盘可达数十秒
- 深度 6：不建议日常使用

若中盘深度 4 耗时过长，可将深度调低至 2 或 3。
